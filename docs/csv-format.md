# CSVフォーマット仕様書

売上分析ダッシュボードに取り込めるCSVの形式です。
毎月のアップロードを担当される方向けの資料です。

---

## 1. 最初に確認していただきたいこと（文字コード）

**Excel で保存するときは「CSV UTF-8 (コンマ区切り)」を選んでください。**

Excel の保存形式には、名前のよく似た2つがあります。

| 保存形式 | 使えるか |
|---|---|
| CSV UTF-8 (コンマ区切り) (*.csv) | **こちらを使ってください** |
| CSV (コンマ区切り) (*.csv) | 使えません |

下を選びますと商品名やカテゴリが読み取れず、その行はスキップされます。
画面には次のように表示されますので、保存し直して再度アップロードしてください。

```
文字コードが UTF-8 ではないため読み取れません
（Excel では「CSV UTF-8 (コンマ区切り)」で保存し直してください）
```

Shopify からダウンロードしたCSVをそのままお使いいただく場合は、
UTF-8 ですのでこの操作は不要です。**Excel で開いて保存し直したときだけ**
ご注意ください。

---

## 2. 必要な列

### 必須の列（7つ）

1つでも欠けているとアップロードできません。

| 列名 | 内容 | 例 |
|---|---|---|
| `order_date` | 注文日 | `2025-09-03` |
| `customer_id` | 顧客ID | `C0012` |
| `product_name` | 商品名 | `ウールコート` |
| `sku` | 商品コード | `SKU-CT-001` |
| `quantity` | 数量 | `2` |
| `revenue` | 売上金額（円） | `24800` |
| `cost` | 原価（円） | `9800` |

### 任意の列（1つ）

| 列名 | 内容 | 未入力のとき |
|---|---|---|
| `category` | カテゴリ | **「未分類」として集計します** |

カテゴリが空欄の行も、売上・粗利の合計には必ず含まれます。
カテゴリ別売上の内訳に「未分類」が出ている場合は、
元データにカテゴリの入っていない行があるということです。

### 列の並び順

**並び順は問いません。** 列名で判定していますので、
Shopify の出力順のままで問題ございません。

### 列名の表記ゆれ

次の書き方はすべて同じ列として扱います。
大文字・小文字、スペース、ハイフンの違いも吸収します。

| 内部の列名 | 認識できる書き方 |
|---|---|
| `order_date` | `Order Date` / `orderdate` / `date` / `created_at` / `注文日` / `日付` |
| `customer_id` | `Customer ID` / `customerid` / `customer` / `顧客id` |
| `product_name` | `Product Name` / `productname` / `product` / `商品名` |
| `category` | `Category` / `カテゴリ` / `カテゴリー` |
| `sku` | `SKU` / `商品コード` |
| `quantity` | `Quantity` / `qty` / `数量` |
| `revenue` | `Revenue` / `sales` / `amount` / `売上` / `売上金額` |
| `cost` | `Cost` / `原価` |

上記に無い書き方をされている場合は、列名を変更していただくか、
ご連絡いただければ対応を追加いたします。

## 3. 各列に入れられる値

### `order_date`（注文日）

次の3つの形式に対応しています。

```
2025-09-03
2025/09/03
2025.09.03
```

月日は1桁でも構いません（`2025-9-3`）。
実在しない日付（`2025-02-30` など）はスキップされます。

**時刻の入った形式（`2025-09-03 14:30:00`）には対応していません。**
Shopify の出力に時刻が含まれる場合は、日付のみの列をご用意ください。

### `revenue` / `cost`（売上・原価）

円単位の数値です。次の記号は自動で取り除きます。

```
24,800   → 24800
¥24,800  → 24800
```

**空欄はスキップされます。** 0円の行として扱うことはいたしません。
「空欄なのか、本当に0円なのか」を取り違えますと合計金額が狂うためです。
0円の行を集計に含めたい場合は、`0` と明記してください。

**マイナス値（返品・キャンセル）は有効な行として取り込み、
合計から差し引きます。** 現在の設定は既存Excelとの一致を優先しております。
返品行を集計から除外する運用をご希望の場合は、ご相談ください
（→ 申し送り事項 `docs/handover.md`）。

### `quantity`（数量）

**0以外の整数**です。小数（`1.5`）と0はスキップされます。
返品行のマイナス値（`-1`）は有効です。

### `customer_id`（顧客ID）

リピート率の算出に使います。空欄の行はスキップされます。

同じお客様には毎月同じIDが振られている必要があります。
月ごとにIDが変わる場合、リピート率が実際より低く出ます。

**顧客IDが外部に送信されることはありません。**
AI分析へ渡すのは集計後の数値のみです。

### `sku`（商品コード）

SKUランキングの集計単位です。空欄の行はスキップされます。
同じ商品に複数のSKUが振られている場合、ランキング上は別商品として並びます。

## 4. スキップされた行の確認方法

取り込み後、画面に次のように表示されます。

```
◯行取り込み / ×行スキップ
```

スキップがあった場合は「**内訳を見る**」で行番号と理由をご確認いただけます。
「**スキップ行をCSVで保存**」で、該当行だけをCSVとして持ち帰れます。
元のCSVの何行目かが入っておりますので、修正して再アップロードしてください。

**スキップされた行は集計に含まれません。**
合計金額が想定と異なる場合は、まずここをご確認ください。

### スキップの理由と対処

| 表示される理由 | 対処 |
|---|---|
| 文字コードが UTF-8 ではないため読み取れません | 「CSV UTF-8 (コンマ区切り)」で保存し直す |
| `order_date` が日付として解釈できません | 日付の形式を確認する（時刻が入っていないか） |
| `customer_id` が空です | 顧客IDを補う |
| `product_name` が空です | 商品名を補う |
| `sku` が空です | 商品コードを補う |
| `quantity` が 0 以外の整数ではありません | 小数や0になっていないか確認する |
| `revenue` が数値ではありません | 空欄か、数値以外が入っている |
| `cost` が数値ではありません | 同上 |
| Too many fields / Too few fields | その行だけ列数が違う。商品名にカンマが含まれていないか確認する |

商品名にカンマが含まれる場合は、`"ワンピース, 花柄"` のように
ダブルクォートで囲んでください。

## 5. その他

**空行は無視します。** 途中に空行があっても、スキップ行には数えません。

**1,000行を超えるデータも正しく集計します。** 2,500行での動作を確認済みです。

これを大きく超える件数のCSVをお使いになる場合は、事前にご相談ください。
本番と同じ件数での確認を行ったうえでご報告いたします
（→ `docs/handover.md` 4-1）。

**画面に表示されるのは、最後にアップロードしたCSVの内容だけです。**
前回のアップロードと合算されることはありません。

そのため、**毎月のCSVには過去の月も含めてください。**
11月分だけをアップロードしますと、前月比と月次推移が表示されなくなります。
詳しくは運用マニュアル（`docs/operation-manual.md`）の第3項をご覧ください。

**動作確認用のサンプル**は `sample-data/case8-sales-sample.csv` にございます
（40件・2025年9〜11月）。形式に迷われた場合はこちらをご参照ください。
